# FreeRemoteDesk UI Icons

`material-symbols-rounded-24-400.ttf` is an offline subset of Google's
Material Symbols Rounded variable font. It contains only the glyphs used by
the session title bar and the login experience, sorted by official name:

- `check_circle`, `close`, `content_paste`, `content_paste_off`, `delete`
- `desktop_windows`, `dns`, `drag_indicator`, `error`, `expand_more`, `fullscreen`
- `fullscreen_exit`, `hourglass_top`, `link_off`, `lock`, `login`, `more_horiz`, `open_with`
- `pending`, `person`, `progress_activity`, `remove`, `shield_lock`, `visibility`
- `visibility_off`, `volume_off`, `volume_up`

The subset is pinned to upstream commit
`84ccef280841abfac506afc4ad4a2782f6d0a1d0`, instantiated at optical size 24,
weight 400, fill 0, and grade 0, then reduced with FontTools 4.63.0. The
upstream variable font SHA-256 was
`C4416E02739ED6865E3218C19DCD62C5A88FB97B8BCC445F24AE8017D11CC2D0`; the
pinned official codepoint source SHA-256 was
`2CEABD8B6EBA5EF81FF6F2FA8A801397F550841BF9CC42B03B5CC2E2D7AEC9F1`.
The update script verifies every configured name/codepoint against that source
before subsetting. The committed subset SHA-256 is
`59519851E1529F27BD74A047AF872CB6C3DF920A50214194A1C11DF4246D8B46`.
