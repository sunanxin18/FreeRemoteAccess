# RemoteFX 色彩转换预检与 SIMD 转换验证

日期：2026-10-14。范围为私有 checked native 色彩转换、macOS ARM64 宿主正确性与实际对象观察；不代表鸿蒙或其它架构的完整解码、性能、包及真实登录资格。

## 实现与正确性

`frd-rdp-legacy-kernels` 的色彩转换保持原有合法输入域、checked 中间式顺序和错误原子性。第一遍先验证全部完整组及短尾；第二遍使用同一不可变输入执行 SIMD 数值转换和写出，不再重复溢出检查。没有增加整 tile 分配或复制，也没有改变协议、公共接口、CPU 探测、默认解码策略及 codec 广告。

候选 native.rs SHA-256 为 `d78a515e268566e476b4610aa118485d3a98ac65b8cf1baf027d1456ff1688d4`；新增测试 SHA-256 为 `56f154b5475d4c70545adde5c378b42a28adb3085e8cd45e2b5ce8f64fd57f14`。固定 Rust 1.96 的候选 debug/release 各 11 项聚焦测试通过，包含独立原版数值、短尾、长度、晚发生错误不写输出、wire 和保护页。五类编译后故障变体在两个 profile 中各自由语义断言检出，共十次预期失败，没有将编译错误或零测试当成负例成功。

旧实现首次测试记录使用共享缓存，不足以证明执行文件来源；该记录保留。随后仅补跑旧实现，使用此前不存在的独立 target，debug/release 各四项通过。实际 Compiling、Cargo fresh=false、独立 package/运行路径和保留执行文件身份补齐了旧源码来源证明。候选及故障变体没有重跑。源码、正确性及这次补证均经独立复审接受。

## 固定宿主微测量

旧、新两侧各自独立全新 release 构建，真实编译参数为 opt3、thin LTO、16 codegen units、macOS ARM64，driver 和 kernel 均为 fresh=false、非 test 产物。两侧真实依赖图、源码、独立参考、调用文件与保留文件 SHA 已核对；全部产物来源记录在第一次计时之前完成。

## 实际 ARM64 对象

两侧实际保留 Mach-O 的 nm 确认 color 范围：OLD 1604 bytes、NEW 1904 bytes。四个有界 nm/objdump 命令实际 exit 0；独立读取真实指令及控制流确认 NEW 完整组和短尾预检成功支配全部 caller 输出写入，第二遍完整组与短尾转换保留 NEON，且没有重复 overflow reduction。

短尾预检在机器码中位于转换代码之后，但真实分支先跳到该预检，再返回转换，因此不能根据物理排列或整函数助记符总数判断原子性或宣称“14 条变 7 条”。第一遍完整组及短尾分别仍保留七项检查。对象 text 增加 300 bytes、stack frame 从 448 降至 160 bytes 是本次代码生成事实，不提供时间归因或速度保证。

本次精确 NEW 对象的控制流/NEON/check-placement 观察经独立复审接受。没有取得 OHOS 新 ELF、SSE2/i686/AMD64、其它平台实际对象、完整管线、包或真实会话证据。
