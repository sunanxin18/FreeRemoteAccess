状态：**实验性**。既有默认关闭的 `mvs-native-colors-arm64` 后端补全两个 type-0 RGB 拷贝 helper 的 ARM64 实现；宿主、官方 OHOS 最终 ELF 与手机/PC 模拟器固定正确性通过。没有性能结论，未注册普通 Harmony 应用 Apple factory，不能据此声明鸿蒙可远程 Mac。

## 实现与不变量

范围仅 `crates/frd-protocol-apple/src/mvs_full.rs`、`mvs_pixels.rs`、`mvs_pixels_arm64.rs` 及新私有 `mvs_copy_tests.rs`。默认原像素循环保持，原循环另作测试 oracle；Cargo、feature 默认、依赖、协议/发布接口、type-1 Copy、旧 fixture 未改。

- committed 来源按实际 surface/rect stride 逐行搬运 live width；保留写入前完整 source 几何检查。
- 混合来源按 dy/x 递增切 committed 左段、live overlay 交集、committed 右段。裁剪目标不会错误裁剪 source tile；10×16 wire 例仍得到目标下半块每行 2 白 + 6 黑。
- live overlay 使用单独私有 forward span，从同一独占 slice 派生 raw pointer；每次不重叠 chunk 不大于两起点距离，保留向右逐像素传播与纵向逐行传播。没有创建重叠 shared/mut slice。type-1 仍作完整 operation 快照。
- 私有 ARM64 叶精确搬运 1..8 pixels / 3..24 bytes，允许任意字节对齐。16/8 字节使用 q/d 寄存器，剩余 4/2/1 使用 ARM64 整数寄存器汇编，范围外不预读/写入。无 Rust scalar production tail 或 libc dispatch。
- 沿用小端 AArch64/baseline NEON 编译门；其他架构不能选择该 feature。未改 Windows/Linux 的已有默认，未恢复 macOS Intel。

独立 Spec PASS / Quality PASS 审查覆盖 unsafe 契约、compiler memory/flags/register clobber、逐段别名证明及实际代码生成。root 复核完整报告、当前源、测试和原始目标证据。
